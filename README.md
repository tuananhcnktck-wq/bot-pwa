# 🔐 CryptoBot PWA

Ứng dụng quản lý thu chi cá nhân - Hoàn toàn offline, bảo mật AES-256

## ✨ Tính năng

- 💰 Quản lý thu/chi theo tháng
- 📊 Thống kê chi tiêu theo hạng mục
- 📋 Lịch sử giao dịch
- 💾 Backup/Export dữ liệu
- 🔐 Mã hóa AES-256
- 📱 PWA - Cài như app native
- ⚡ Offline hoàn toàn

## 🚀 Cách dùng

### Trên iPhone:

1. Mở Safari
2. Truy cập: https://YOUR_USERNAME.github.io/cryptobot-pwa
3. Nhập mật khẩu (≥12 ký tự)
4. Tap Share (↑) → Add to Home Screen
5. Xong!

### Mật khẩu:

- Tối thiểu 12 ký tự
- Càng dài càng an toàn
- Ghi nhớ kỹ - quên = mất data!

## 📊 Hạng mục mặc định

**Thu nhập:**
- Lương
- Thưởng
- Công việc phụ
- Đầu tư
- Khác

**Chi tiêu:**
- Ăn uống
- Nhà ở
- Di chuyển
- Giải trí
- Mua sắm
- Học tập
- Y tế
- Khác

## 🔒 Bảo mật

- Data mã hóa AES-256
- Lưu trong Safari LocalStorage
- Không upload lên server
- Hoàn toàn offline

## 💾 Backup

- Tap "💾 Backup" để xuất file .enc
- Lưu file vào iCloud/Files
- Khôi phục: (tính năng sắp có)

## ⚠️ Lưu ý

- Không xóa Safari cache
- Backup thường xuyên
- Ghi nhớ mật khẩu
